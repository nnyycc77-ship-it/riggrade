# Compute supply ledger: weekly notes

One note per week, written by `pricewatch.ledger_note` from the reconstructed
index (link 4) after the Tuesday import, under `docs/compute-supply-method.md`.
Every note opens and closes with the method's four posture statements. Notes
are never edited after publication; a correction is a new note that names the
old one. Information, not advice, and not an offer, a rate or a forecast.
